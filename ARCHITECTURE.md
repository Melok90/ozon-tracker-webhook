# 🏗️ Архитектура проекта

## Компоненты системы:

```
┌─────────────────────────────────────────────────────────┐
│                    ПОЛЬЗОВАТЕЛЬ                          │
│                   (Telegram User)                        │
└─────────────────┬───────────────────────────────────────┘
                  │
                  │ открывает Mini App
                  ↓
┌─────────────────────────────────────────────────────────┐
│            TELEGRAM MINI APP (HTML)                      │
│         ozon-tracker-api.html                           │
│  • Интерфейс добавления товаров                         │
│  • Отображение мониторингов                             │
│  • LocalStorage для хранения                            │
└─────────────────┬───────────────────────────────────────┘
                  │
                  │ HTTP POST /api/price
                  ↓
┌─────────────────────────────────────────────────────────┐
│            FLASK API (Railway)                           │
│         bot_with_api.py (порт 5000)                     │
│  • GET  /api/health  - проверка статуса                │
│  • POST /api/price   - получение цены                  │
│  • GET  /api/monitors - список мониторингов            │
└─────────────────┬───────────────────────────────────────┘
                  │
                  │ requests.get()
                  ↓
┌─────────────────────────────────────────────────────────┐
│              OZON.RU (парсинг)                          │
│  • HTML страница товара                                 │
│  • BeautifulSoup парсинг цены                          │
└─────────────────────────────────────────────────────────┘

ПАРАЛЛЕЛЬНО:

┌─────────────────────────────────────────────────────────┐
│         TELEGRAM BOT (python-telegram-bot)               │
│         bot_with_api.py (тот же процесс)                │
│  • Команды: /start, /monitor, /status, /stop           │
│  • Job Queue: проверка каждые 2 часа                   │
│  • Отправка уведомлений при снижении цены              │
└─────────────────┬───────────────────────────────────────┘
                  │
                  │ отправка сообщений
                  ↓
┌─────────────────────────────────────────────────────────┐
│                  ПОЛЬЗОВАТЕЛЬ                            │
│         (получает уведомления в Telegram)               │
└─────────────────────────────────────────────────────────┘
```

## Поток данных:

### 1. Добавление товара:
```
User → Mini App → POST /api/price → Flask → Ozon (парсинг) → Flask → Mini App → LocalStorage
```

### 2. Проверка цены вручную:
```
User нажимает "Обновить" → Mini App → POST /api/price → Flask → Ozon → Flask → Mini App
```

### 3. Автоматическая проверка (фон):
```
Job Queue (каждые 2 часа) → get_price() → Ozon → если цена ≤ цели → Telegram notification
```

## Технологии:

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Frontend | HTML + CSS + JS | Интерфейс Mini App |
| Backend | Python + Flask | API для парсинга |
| Bot | python-telegram-bot | Telegram уведомления |
| Парсинг | BeautifulSoup + requests | Получение цен с Ozon |
| Хостинг | Railway.app | Деплой 24/7 |
| Хранилище (Mini App) | LocalStorage | Локальное хранение мониторингов |
| Хранилище (Bot) | In-memory dict | Хранение мониторингов бота |

## Особенности реализации:

### ✅ Преимущества:

1. **Один процесс** - Flask + Telegram Bot работают параллельно в threading
2. **Без базы данных** - LocalStorage для Mini App, dict для Bot
3. **CORS enabled** - Mini App может обращаться к API
4. **Реальный парсинг** - не демо-данные, реальные цены
5. **Автономность** - Mini App работает даже при недоступности API

### ⚠️ Ограничения:

1. **In-memory storage** - мониторинги сбрасываются при перезапуске
2. **Один user в Bot** - Bot хранит по одному мониторингу на chat_id
3. **Rate limiting** - Ozon может блокировать частые запросы

### 🔮 Будущие улучшения:

1. **PostgreSQL** вместо in-memory хранилища
2. **Redis** для кэширования цен
3. **Celery** для фоновых задач
4. **Webhooks** вместо polling для бота
5. **User authentication** для синхронизации между Mini App и Bot
